## 📌 문제

우리는 연산 횟수를 일일이 구하는 수고를 덜기 위해, 수학에서 사용하는 점근적 표기법이라는 방법을 사용해 시간 복잡도를 표현하려고 합니다. 다음 함수들이 주어졌을 때, 보기 중 옳은 것을 모두 고르세요.

- $f_1(x) = x^2$
- $f_2(x) = x^3 + x^2 + x + 1$
- $f_3(x) = x! - x \log x + x^x$

---

## 🔍 보기별 해설 및 분석

먼저 각 함수의 최고차항(가장 빠르게 증가하는 주된 항)을 파악해야 합니다.

1. $f_1(x) = x^2$ $\rightarrow$ 최고차항: $x^2$
2. $f_2(x) = x^3 + x^2 + x + 1$ $\rightarrow$ 최고차항: $x^3$
3. $f_3(x) = x! - x \log x + x^x$ $\rightarrow$ 일반적인 함수 증가 속도 순서($\log x < x < x^2 < x^3 < 2^x < x^x < x!$)에 따라, 가장 빠르게 증가하는 항은 $x!$ (팩토리얼) 또는 $x^x$입니다. 보통 이와 같은 다항/지수/계승 혼합식에서는 $x^x$나 $x!$이 최상위 항이 됩니다. 여기서는 $x^x$와 $x!$ 모두 $x^2$이나 $x^3$보다 훨씬 거대하게 성장합니다.

---

제공해주신 실제 해설 이미지를 바탕으로, 아까 나눈 개념과 해설을 결합하여 보기별로 완벽하게 마크다운으로 정리해 드립니다.

---

## 📌 문제 분석

### 1. 해설 기반 보기별 상세 풀이

- **①번 보기: $\log x = O(f_1)$ (정답)**
- **해설 반영:** $x$를 무한히 키웠을 때, $f_1 = x^2$은 $\log x$보다 훨씬 커집니다. 따라서 $f_1$이 상한(더 크거나 같은 기준)이 되므로 해설에서는 **$O(f_1) = \log x$** 형태로 표현하여 참(정답)으로 처리했습니다.

- **②번 보기: $x^5 = \Omega(f_2)$ (정답)**
- **해설 반영:** $f_2$는 최고차항이 $x^3$인 3차 다항식입니다. $\Omega$(빅-오메가)는 하한(적어도 이만큼은 크다)을 뜻하므로, $f_2$보다 차수가 높은 $x^5$는 $\Omega(f_2)$가 성립하므로 정답입니다.

- **③번 보기: $x \log x = \Theta(f_3)$ (오답)**
- **해설 반영:** $f_3$에는 $x^x$이나 $x!$(계승)처럼 $x$를 무한히 키웠을 때 $x \log x$보다 비교할 수 없을 정도로 훨씬 거대하게 커지는 항들이 포함되어 있습니다. 따라서 성장이 완전히 다르므로 $\Theta$(세타)를 쓸 수 없습니다. (대신 해설에서는 $O(f_3) = x \log x$ 형태의 상한 표현을 언급하고 있습니다.)

- **④번 보기: $x = \Omega(f_1)$ (오답)**
- **해설 반영:** $f_1 = x^2$의 최고차항 차수가 $x$보다 높으므로, 하한 관계($\Omega$)가 성립하려면 기준과 대상이 반대가 되어야 하므로 이 보기는 옳지 않습니다. (해설에서는 $O(f_1) = x$ 형태의 관계를 설명하며 4번 자체는 오답 처리함)

- **⑤번 보기: $x \log x = O(f_2)$ (정답)**
- **해설 반영:** $x$가 무한히 커질 때, $f_2$의 가장 높은 차수인 $x^3$은 $x \log x$보다 훨씬 빠르게 커집니다. 즉, $f_2$가 상한(더 큰 기준) 역할을 할 수 있으므로 **$O(f_2) = x \log x$** 관계가 성립하여 정답입니다.
